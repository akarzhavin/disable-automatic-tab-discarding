# Keep Tabs Alive — Disable Automatic Tab Discarding

## Short description (≤132 chars, for the store header)

Disable Chrome tab discarding and stop tabs slowing down in the background. Per-site and per-tab control, auto-off timer.

## Detailed description

**Ever switched back to a tab and found it reloading from scratch?**

Chrome's Memory Saver automatically discards inactive tabs to free RAM. When you
return, those tabs may reload from scratch instead of resuming instantly — which
can interrupt your workflow, reset page state, potentially lose form data and
force unnecessary reloads. **Keep Tabs Alive** gives you full control over which tabs
Chrome is allowed to discard — so the tabs that matter stay exactly where you
left them.

Keep Tabs Alive lets you **disable automatic tab discarding**, **prevent
unwanted tab reloads** and **keep important tabs active** — whether you manage
them by website or one tab at a time.

No unexpected reloads. No lost work. No surprises.

### Why Keep Tabs Alive?

- Prevent unwanted tab reloads caused by tab discarding
- Disable Chrome's Memory Saver tab discarding
- Protect important web apps, dashboards and ongoing work
- Keep forms and workflows intact
- Control tabs individually or by website
- Works entirely offline
- No tracking, no analytics

### Perfect for

Gmail · Outlook Web · Google Docs · Notion · Jira · GitHub · trading and

### ✨ Features

- **Master switch** — pause or resume all protection from the settings page in one click.

- **Two protection modes**
  - **Protect everything** — keep every tab alive, except the sites you exclude.
  - **Whitelist only** — keep alive only the sites you choose.

- **Per-site rules** — protect or exclude the current site in one click. Domain
  rules also cover subdomains — `example.com` automatically covers
  `mail.example.com`.

- **Per-tab switches** — the settings page lists every open tab (searchable,
  grouped by window) with its own switch. Keep a single tab alive or let it
  sleep — a one-time choice that lasts until you close the tab. Like it? Turn it
  into a permanent site rule with one click.

- **Toolbar badge** — see at a glance how many tabs are currently protected.

- **Keep running** — for a tab that must keep working while hidden (chats,
  timers, live data). Switch it on for one tab and Chrome treats it as in use,
  so the page isn't slowed down in the background. It is opt-in per tab, with an
  auto-off timer (30 min, 1 h, 3 h or none) that you can extend at any time.
  Chrome shows its screen-sharing indicator while it is on; nothing is ever
  recorded, stored or sent anywhere. It uses more battery, so use it only where
  you need it.

- **At-a-glance list** — the popup lists every tab that is kept running or kept
  in memory, each with a one-click off button.


- **Light / Dark / Auto themes** — a clean interface that can follow your OS.

- **Guided tour** — a quick walkthrough so you're up and running in seconds.

- **50+ languages** — the interface is fully localized.

### 🔒 Privacy first

Keep Tabs Alive collects **no data**. There are no analytics, no tracking and no
external servers. All your settings and stats live entirely in your own browser.
It requests only the permissions it needs: `tabs` and `storage` for
protection and — only for the optional Keep running feature — `tabCapture`,
`activeTab`, `scripting` and `offscreen`. Keep running never reads, records or
transmits the picture of your tab; the open capture is simply what tells Chrome
the tab is in use.

### 🛠️ How it works

A lightweight background service worker marks your chosen tabs as
non-discardable (Auto Discardable = false), re-evaluating whenever tabs are created, updated, or when your
settings change. It's built on Chrome's own Manifest V3 platform — fast,
modern and efficient, with no runtime dependencies.

### ✅ Verify it works

Open `chrome://discards` — the **Auto Discardable** column shows ✕ for every
protected tab, and the toolbar badge matches the count.

> Note: Keep Tabs Alive only blocks Chrome's **automatic** memory-saver
> discarding. You can still discard any tab manually from `chrome://discards`.
